# koe-matome

推し（ライバー）のボイス商品を、販売期間と税込価格つきの購入リストにまとめる**非公式**ツールです。
ボイスの販売ページは、どれがいつまで買えるのか分かりにくく、ページも重いので、必要な情報だけを手元の1ファイルにまとめます。

- 今の対応サイト：にじさんじオフィシャルストア
- 出力：ダブルクリックで開ける1つのHTMLファイル（サーバー・アカウント不要）
- 購入記録・ほしい印はブラウザに保存し、どこにも送信しません。ファイルか引き継ぎコードで別の端末へ移せます

> **このツールは ANYCOLOR株式会社、株式会社ソニー・ミュージックソリューションズ、にじさんじオフィシャルストアとは関係ありません。**
> 商品情報の権利は各権利者に帰属します。購入前に必ず公式の販売ページを確認してください。

## 必要なもの

- Python 3.9 以上（標準ライブラリだけで動きます。追加のインストールは不要）

## 使い方

```sh
git clone https://github.com/iknoway-home/koe-matome.git
cd koe-matome

# 1. ライバーを名前で探す（名前の一部でよい）
python3 -m koe_matome members 戌亥

# 2. 推しを指定して取得（複数指定できる）。数分かかる
python3 -m koe_matome update --member 戌亥とこ --member 栞葉るり

# 3. できたファイルを開く
open koe-data/koe-matome-nijisanji.html      # Windows は start、Linux は xdg-open
```

2回目からは `python3 -m koe_matome update` だけで、前回指定したライバーの分を差分で更新します。
変わった商品だけ取り直すので、ふだんは1〜2分で終わります。

| コマンド | すること |
|---|---|
| `members [名前]` | ライバー一覧を取得して名前で探す |
| `update --member 名前` | 指定したライバーの商品を取得してHTMLを作る（指定は保存される） |
| `update` | 前回の指定のまま差分更新 |
| `update --all` | 全員分を取得する。初回は数時間かかる。ストアの担当情報にない卒業生の商品も拾いやすい |
| `update --offline` | 通信せず、保存済みのデータからHTMLを作り直す |
| `build` | HTMLだけ作り直す |

データは `./koe-data/` に保存されます（`--data` で変更可）。このフォルダは各自の手元だけで使うもので、共有や再配布はしないでください。

## ページでできること

- 「ライバーを選ぶ」で表示する人を選び、1人ずつにも絞り込める
- 販売終了が近い未購入の企画を、残り時間つきで上部に表示
- 通常版・EX・セットを別々に購入チェック（押し間違いを防ぐ2段階確認つき）、「ほしい」印と金額の集計
- 「購入できる期間のみ」「期間限定のみ」「購入済みを隠す」などの絞り込み
- 記録をファイルか引き継ぎコードで書き出し、別の端末で読み込む（今の記録に足す／置き換えるを選べる）
- 購入済みの候補を探して一括でチェックできる。確かめてから記録し、同じものを何度入れても記録は増えない
  - ダウンロードしたボイスのファイル・フォルダ・ZIPをページに落とすと、ファイル名（`shioriha-ruri-birthday2026.mp3` など）や曲名タグから近い商品を出す。ライバーの英語表記・年・英語とローマ字の小さな対応表で照合し、商品名の英訳データは持たない
  - ストアの購入履歴ページや注文確認メール（貼り付け、.eml、保存した .html）からも、商品名の一致と文字の近さで探す
  - ファイルや文章はページの中で読むだけで、保存・送信しない。音声の中身は読まない。ツールがログインして履歴を取りに行くことはしない

## 取得のルール（守ってほしいこと）

このツールは取得先のサイトに負担をかけないよう、次のように作っています。変えないでください。

- **アクセスは1秒に1件まで**（`koe_matome/net.py`）。並列で動かさない
- 商品の最終更新日時（サイトマップ）を見て、**変わった商品だけ**取り直す
- 取得するのは誰でも見られる公開ページの情報だけ。ログインが必要な場所には触れない
- 画像や商品説明文は保存・表示しない（販売期間を読み取るために説明文を一時的に使うだけ）
- ライバーの英語表記は、公式サイトのタレント一覧を `members`・`update` のときに1回だけ読む（ファイル名との照合用）

使う人それぞれに、取得先サイトの利用規約が適用されます。取得したデータや作ったHTMLを公開・再配布しないでください。
取得先から中止を求められた場合、このツールの該当サイト対応は取り下げます。

## 仕組み

```
koe_matome/
  __main__.py      コマンドの入口
  catalog.py       メンバーと商品の更新（差分の判断、担当ライバーの判定、卒業生の登録）
  page.py          1ファイルのHTMLを作る（CSS・JS・データを埋め込む）
  net.py           取得（1秒1件の間隔を固定）
  storage.py       手元データの読み書き
  sites/
    nijisanji.py   にじさんじオフィシャルストア用の取得と読み取りの規則
  template/        ページのHTML・CSS・JS
tests/             読み取り規則とページ生成のテスト（通信なし）
```

- 購入記録はストアの商品ID（選択肢ごとのID）で保存するので、データを作り直しても記録は消えません
- ストアから消えた商品や、一覧から外れたライバーも削除せず残します

テスト：

```sh
python3 -m unittest discover -s tests
```

## ほかのサイトに対応させるには

`koe_matome/sites/nijisanji.py` と同じ関数（メンバー一覧、商品一覧、商品の取得、販売期間・担当ライバーの読み取り）をそろえたモジュールを作り、
`koe_matome/sites/__init__.py` の `SITES` に登録します。対応を足す前に、そのサイトの利用規約と robots.txt を確認してください。
